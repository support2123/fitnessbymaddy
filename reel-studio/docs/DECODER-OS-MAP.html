The pre-publish gate — ten checks, then the scanner

  1. Screenshot Test — freeze any frame; if a claim is on it, its source ships with it
  2. Citation on screen — Author · Year · Journal, held ≥ 2 s, legible at thumbnail size
  3. Numbers wear units and match the registry (one value, everywhere)
  4. Zero woo — Forbidden Lexicon scan + One-Swap Test; surface names NEURAL / RESPIRATORY / METABOLIC / FLUID / STRUCTURAL
  5. Confidence tiers — T1 fact · T2 “one study found” + n · T3 “an estimate”; correlation never sold as causation
  6. Medical scope — educational framing only, clinician hand-off on red-line topics
  7. Attack claims, not people; no fear-bait, no fake scarcity; 85 % teach / 15 % ask
  8. Contradiction gate — reconcile against prior posts before publishing
  9. Fresh eyes ≥ 8, no un-fixed criticals; cover + caption pack ready
  10. brand_gate.py PASS, then sterile publish (no tool metadata, no x264 SEI)
Automated companion: python3 tools/engine/brand_gate.py episodes/<EP> — blocks mystical vocabulary, elemental names on screen, on-screen numbers with no citation, mortality claims with no bounding line, and any un-cleared price. New episodes start with: python3 tools/engine/new_episode.py --list.
