## Frame language

- **Format:** 1080×1920 / 30 fps / 9:16. Safe core: x 90–990; y 250–1590. CTA text: y 800 / 980 / 1180. Trace band: y 1440–1560.
- **Colour:** graphite `#101115`; bone `#F5F1E8`; myth red `#FF1F1F`; truth/protocol gold `#D4A148` / `#E8BC6A`; data cyan `#38D8E0`.
- **Red rule:** max one red element per frame. Red and gold never compete as equal heroes.
- **Type:** Druk Wide Bold fallback → Monument Extended → Anton for hook, big numbers and CTA; Anton for captions; Space Mono tabular figures for chapter kickers, source chips, bounds and HUD.
- **Scale ladder:** only 28 / 42 / 64 / 96 / 144 / 216 / 324 / 486. Maximum two headline sizes on one frame.

## Motion system

- Every number except the living clock: 1.18 → 0.96 → 1.00 over 7 frames; blur 3 px → 0; y +14 → 0; one-frame 6% bloom; impact SFX.
- Charts use 2 px outlined rounded bars filling upward in 12 frames, ease-out; label pops when bar settles; max two bars per chart.
- Spoken captions: Anton, word-by-word clip mask / 3-frame y-rise, white/bone with 8 px black stroke, baseline y ~1100. Captions are OFF for m08 CTA.
- One 2 px breathing waveform lives in bottom trace band; baseline rises as the illustrative clock progresses. It is atmospheric—not a health measurement.
