# REQUEST CARD

```text
TOPIC:        <one clear subject>
DURATION:     auto | 15s | 30s | 45s | 60s | 90s | 2min
TIP:          <optional fact, myth, angle, mood, or audience steer>
```

## Rules

- `auto` lets the duration router select the shortest tier that completely teaches the topic.
- A tip is a steer, never a pre-approved claim. Every number still needs a locked citation.
- The operator retains three approvals only: research spine, final script, and publish.
- A new reel begins with this card, not with a request for an arbitrary visual or voice render.
